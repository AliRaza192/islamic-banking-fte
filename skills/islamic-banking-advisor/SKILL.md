# Islamic Banking Advisor Skill

## GOVERNING FRAMEWORK

Every advisory response MUST begin with:
```
GOVERNING FRAMEWORK: AAOIFI Shariah Standards — [Jurisdiction]
PRODUCT: [Product/Service being advised]
JURISDICTION: [Country — Regulator]
```

## When to Activate
- User asks for bank or product recommendation
- User asks general "how does Islamic banking work" questions
- User is comparing Islamic vs conventional banking
- User wants to know how to start with Islamic banking

## Advisory Framework

**Step 1: Understand the Need**
Ask:
- What are you trying to finance / achieve?
- What is your approximate budget or amount?
- How long can you commit (tenure)?
- Any preference for specific bank?

**Step 2: Match to Product**
```
Need a car          → Car Ijarah (Meezan) or Car Murabaha
Need a home         → Diminishing Musharakah (all major Islamic banks)
Need business fund  → Musharakah or Running Murabaha
Want to save        → Mudarabah savings account
Want to invest      → Islamic mutual funds or Sukuk
Need insurance      → Takaful
Need a small loan   → Qard Hasan (Akhuwat)
```

**Step 3: Recommend Bank**
Load references/pakistan-banks.md for current options.

## Opening an Islamic Account — Steps
1. Visit any Islamic bank branch OR their website/app
2. Bring: CNIC, one photo, initial deposit (varies by bank)
3. Choose: Current (Qard Hasan) or Savings (Mudarabah)
4. For Islamic home/car finance: bring income proof, CNIC, property/car details

## Key Advisory Points
- Always compare 2-3 banks before deciding
- Ask for the Shariah compliance certificate of any product
- Variable rate products: ask about worst-case scenario (max KIBOR)
- Read the contract before signing — ask Shariah department if unclear
- Meezan Bank's helpline has a dedicated Shariah query service
