# /zakat — Annual Zakat Calculator

## Usage
```
/zakat
/zakat gold 200grams
/zakat savings 800000
/zakat business
```

## Behavior
Activates `zakat-advisor` skill.
Without parameters: Walks user through complete Zakat worksheet interactively.
With parameters: Calculates Zakat on specified asset immediately.

## Interactive Mode (no parameters)
1. Ask for cash/savings amount
2. Ask for gold (grams or tola)
3. Ask for silver (if any)
4. Ask for stocks/investments
5. Ask for business inventory
6. Ask for debts to deduct
7. Calculate and show complete breakdown
8. Remind about current Nisab values
9. Suggest organizations to pay Zakat to
