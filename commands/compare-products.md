# /compare — Islamic Banking Product Comparison

## Usage
```
/compare murabaha ijara
/compare Meezan HBL home finance
/compare takaful insurance
/compare musharakah mudarabah
```

## Behavior
Activates `islamic-banking-advisor` + relevant specialist skills.
Shows side-by-side comparison table.
Recommends which is better for specific use cases.
Always links to references/products.md for full details.

## Comparison Dimensions
- Structure (how it works)
- Ownership transfer
- Rate type (fixed vs variable)
- Who bears risk
- Best use case
- Pakistani banks offering it
- Approximate cost comparison
