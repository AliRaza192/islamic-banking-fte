# Workflow: Islamic Banking Product Comparison

## Trigger
User wants to compare products or banks before making a decision

## Steps

### Step 1 — Clarify What They're Comparing
Ask if not clear:
- Two products (Murabaha vs Ijara)?
- Two banks (Meezan vs HBL Islamic)?
- Islamic vs conventional?

### Step 2 — Gather Context
- Amount needed?
- Asset type?
- Tenure preference?
- Fixed or variable rate preference?

### Step 3 — Run Calculations for Both Options
Use halal-calculator skill for each option with same inputs.

### Step 4 — Build Comparison Table
Show:
- Monthly payment (Month 1)
- Total payable (full tenure)
- Rate type (fixed/variable)
- Ownership structure
- Key risk for customer
- Best for: (use case)

### Step 5 — Recommendation
Give clear recommendation based on user's stated needs.
Always say: "Verify current rates directly with banks before deciding."
