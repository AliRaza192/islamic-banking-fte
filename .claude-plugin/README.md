# Islamic Banking FTE — Plugin Installation

## Quick Install (Claude Code)

```bash
claude plugin install islamic-banking-fte@agentfactory-business
```

## Manual Install

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/islamic-banking-fte
cd islamic-banking-fte
claude plugin install .
```

## Verify Installation

Start a new Claude Code session and type:
```
"I need to calculate Murabaha financing for Rs. 2 million"
```
If the `murabaha-specialist` skill auto-activates, the plugin is working.

## Requirements

- Claude Code (latest version)
- Claude Pro, Max, or API account
- Node.js 18+
